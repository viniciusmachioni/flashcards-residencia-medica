# Flashcards Residência Médica — SUS-SP & USP Bauru

Flashcards coringa interativos (362 cartões, 51 temas) montados a partir da análise de 790 questões de
SUS-SP (2022–2026) e USP Bauru (2024–2026).

Áreas: Clínica Médica, Ginecologia e Obstetrícia, Pediatria, Cirurgia e Saúde Coletiva.

## Como usar
Abra `index.html` no navegador (arquivo único, sem dependências). O progresso fica salvo no próprio navegador.

> Conteúdo de estudo: conferir doses e portarias vigentes (ex.: HPV, eMulti) antes de usar em prática clínica.
